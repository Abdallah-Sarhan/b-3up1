# مساعد ذكي داخل البرنامج

## الوضع الحالي

أدوات المساعد التي أُضيفت سابقًا (ملخص الجناح، قائمة المرضى، البحث، سجل مريض) لا تظهر داخل البرنامج — فهي مخصّصة لتطبيقات ذكاء اصطناعي خارجية بعد نشر التطبيق. تسجيل الدخول في صفحة `/login` لا يُظهر أي شيء جديد داخل البرنامج لأن البرنامج لا يحتوي على نافذة محادثة أصلًا.

هذه الخطة تضيف نافذة محادثة ذكية **داخل** البرنامج تجيب عن بيانات جناح 39.

## ما سيراه المستخدم

- زر "المساعد" في الشريط العلوي يفتح صفحة محادثة.
- قائمة جانبية بالمحادثات السابقة + زر "محادثة جديدة"؛ كل محادثة لها رابط خاص بها.
- المحادثات محفوظة في السحابة لحساب الموظف — تظهر على أي جهاز بعد تسجيل الدخول.
- إذا لم يكن الموظف مسجّل الدخول، تظهر رسالة مع زر يقود إلى صفحة الدخول.
- المساعد يقرأ بيانات المرضى فقط (عدد المقيمين، الغرف، البحث بالاسم أو رقم الملف، سجل مريض) ولا يعدّل أي شيء.
- الإجابات تظهر تدريجيًا أثناء الكتابة، مع عرض مبسّط لما استعلم عنه المساعد.

## نطاق العمل

1. **قاعدة البيانات:** جدولان جديدان `chat_threads` و`chat_messages` مربوطان بحساب الموظف، مع تفعيل الحماية وسياسات تقصر القراءة والكتابة على صاحب الحساب.
2. **الخادم:** مسار محادثة متدفّق يستخدم ذكاء Lovable، مع أربع أدوات قراءة تعيد استخدام منطق أدوات المساعد الموجود (ملخص، قائمة، بحث، سجل مريض) — كلها للقراءة فقط وتعمل بهوية الموظف المسجّل.
3. **الواجهة:** صفحات `/assistant` و`/assistant/$threadId` مبنية على مكوّنات المحادثة الجاهزة (نص متدفّق، مؤشر انتظار، صندوق كتابة، عرض نتائج الأدوات مطويًا)، بالعربية ومن اليمين لليسار.
4. **الربط:** زر في `AppShell`، واستثناء صفحات المساعد من شيء واحد فقط: لا شيء — يبقى قفل الجهاز كما هو.

## تفاصيل تقنية

- الجداول: `chat_threads(id, user_id, title, created_at, updated_at)` و`chat_messages(id, thread_id, user_id, role, parts jsonb, created_at)`؛ `GRANT` للـ `authenticated` و`service_role`، RLS بسياسات `auth.uid() = user_id`.
- مسار الخادم `src/routes/api/chat.ts` مع `streamText` والنموذج `openai/gpt-6-astra` عبر Responses API (`forceReasoning`, `store: false`, `include: ["reasoning.encrypted_content"]`, `stopWhen: stepCountIs(50)`)، ومفتاح `LOVABLE_API_KEY` من `process.env` داخل المعالج فقط.
- الأدوات تُعرَّف بـ `tool()` وschemas متوافقة مع strict (كل الحقول مطلوبة، الاختياري `.nullable()`)، وتستدعي Supabase بالـ bearer token القادم مع الطلب.
- حفظ الرسائل عبر `toUIMessageStreamResponse({ originalMessages, onFinish })`؛ مفاتيح الصفوف UUID من قاعدة البيانات لا معرّفات `msg_...`.
- عمليات إنشاء/قراءة/حذف المحادثات عبر `createServerFn` مع `requireSupabaseAuth`، والتأكد من تسجيل bearer middleware في `src/start.ts`.
- تثبيت مكوّنات AI Elements (`conversation`, `message`, `prompt-input`, `shimmer`, `tool`) وحزم `ai`, `@ai-sdk/react`, `@ai-sdk/openai`.
- `head()` خاص بصفحات المساعد (عنوان ووصف عربي).

## خارج النطاق

- لا تعديل على قفل الجهاز أو كلمة السر أو المزامنة الحالية.
- المساعد لا يضيف أو يعدّل أو يحذف مرضى في هذه المرحلة.
- خطة إرسال رمز الاستعادة بالبريد تبقى معلّقة كما هي.
