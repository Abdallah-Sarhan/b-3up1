# خطة: برنامج سجل مرضى جناح 39 (يعمل Offline على Windows)

## الهدف
برنامج سطح مكتب للابتوب (Windows) يعمل بدون إنترنت، يستبدل ملف الإكسل `WARD39_New_1.xlsx` الخاص بجناح 39 في مركز الكويت للصحة النفسية (KCMH)، ويشمل:

1. **سجل المرضى**: تسجيل مريض جديد، بحث، تعديل، حذف — بنفس حقول ورقة PATIENT DETAILS (رقم الملف، الاسم، الجنسية، التشخيص، رقم الفولدر، العمر، الطبيب المعالج، رقم البطاقة المدنية CID، تاريخ الدخول DOA) مع إضافة الجنس والغرفة/السرير.
2. **استيراد بيانات الإكسل**: تحميل قائمة المرضى الحالية من الملف المرفوع داخل البرنامج تلقائياً + زر "استيراد من Excel" لأي ملف مستقبلي بنفس التنسيق.
3. **طباعة بيانات المريض**: صفحة ملف مريض كاملة قابلة للطباعة.
4. **طباعة نموذج SBAR**: نموذج يُعبأ تلقائياً ببيانات المريض (الاسم، رقم الملف، العمر، التشخيص، CID، DOA، الجنسية، Ward: 39) مع حقول Situation / Background / Assessment / Recommendation / Signature — مطابق لتنسيق ورقة SBAR الحالية وجاهز للطباعة على ورق A4.
5. **نماذج التمريض الأخرى**: Vital Signs (ضغط/نبض/تنفس/حرارة/SpO2 في جدول)، Nurses Notes، Care Plan — كلها بترويسة بيانات المريض وتنسيق طباعة مطابق لأوراق الإكسل.
6. **واجهة ثنائية اللغة**: عربي (RTL) / إنجليزي مع زر تبديل، والمصطلحات الطبية تبقى بالإنجليزية كما هي في النماذج الرسمية.
7. **نسخ احتياطي**: تصدير/استيراد البيانات كملف JSON أو Excel لحفظ نسخة احتياطية.

## تخزين البيانات (Offline بالكامل)
- البيانات تُحفظ محلياً على الجهاز باستخدام IndexedDB (تستوعب آلاف المرضى بسرعة) — لا يحتاج البرنامج إنترنت ولا حسابات ولا خوادم.
- استيراد تلقائي لمرضى ملف الإكسل الحالي عند أول تشغيل.

## الصفحات
- `/` — قائمة المرضى: بحث بالاسم/رقم الملف/CID، فرز، زر "مريض جديد"، استيراد/تصدير.
- `/patients/new` و `/patients/$id/edit` — نموذج تسجيل/تعديل مريض.
- `/patients/$id` — ملف المريض: بياناته + أزرار طباعة (بيانات المريض، SBAR، Vital Signs، Nurses Notes، Care Plan) + سجل العلامات الحيوية والملاحظات المدخلة.
- صفحات طباعة منفصلة بتنسيق A4 (CSS خاص بالطباعة) تُفتح من ملف المريض.

## التحويل إلى برنامج Windows (Electron)
- ضبط `base: './'` في Vite حتى يعمل من `file://`.
- إنشاء `electron/main.cjs` (نافذة BrowserWindow، contextIsolation مفعّل).
- تثبيت `electron` و `@electron/packager`، بناء التطبيق، وتغليفه لـ Windows (win32/x64).
- الناتج: ملف ZIP جاهز للتحميل يحتوي البرنامج التنفيذي (بدون مثبّت `.exe` لقيود بيئة العمل — يُفك الضغط ويعمل مباشرة).

## التصميم
- واجهة نظيفة طبية بألوان هادئة، خط عربي واضح (يُضمَّن محلياً ليعمل بدون إنترنت)، اتجاه RTL عند اختيار العربية.

## ملاحظات تقنية
- المشروع الحالي TanStack Start؛ سأستخدم واجهة React نفسها داخل Electron مع تعطيل أي استدعاءات شبكة.
- النماذج المطبوعة تطابق تخطيط أوراق الإكسل (SBAR / VITAL SIGN / NURSES NOTE / CAREPLAN) قدر الإمكان.
- البيانات الصحية حساسة: كل شيء يبقى على الجهاز ولا يُرسل لأي خادم.

## خطوات التنفيذ
1. تحويل ورقة PATIENT DETAILS إلى ملف بيانات أولي JSON داخل المشروع.
2. بناء طبقة التخزين المحلي (IndexedDB) + الاستيراد/التصدير.
3. صفحات سجل المرضى (قائمة، إضافة، تعديل، ملف مريض).
4. نماذج الطباعة الأربعة + تنسيقات الطباعة.
5. الترجمة الثنائية + RTL.
6. تجهيز Electron وبناء نسخة Windows وتسليمها كملف ZIP.
